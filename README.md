# ARIFEX Lab website

Static website for ARIFEX Lab (Artificial Intelligence Research in Future Exploration Lab), Leading University, Sylhet.

## Pages
index.html, projects.html, students.html, publications.html, datasets.html, about.html. Shared styling is in style.css.

## Photos
Photos go in the `img/` folder. A missing photo shows the person's initials instead. File names:
supervisor.jpg, advisor.jpg, sunny.jpg, sagor.jpg, paramita.jpg, nuzhat.jpg, mahbub.jpg, anjum.jpg,
sammun.jpg, nuzat.jpg, kamran.jpg, sumon.jpg, sagnik.jpg, meem.jpg (square images work best).

## Publish on GitHub Pages
1. Create a public repository (e.g. `arifex-lab`) and upload all files, keeping the `img` folder.
2. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
3. The site will be live at https://arifex.github.io/arifex-lab/
